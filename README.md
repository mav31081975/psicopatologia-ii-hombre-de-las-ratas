# Diacronía de la neurosis obsesiva

Trabajo práctico grupal de Psicopatología II sobre **El Hombre de las Ratas**.

## Página interactiva

https://mav31081975.github.io/psicopatologia-ii-hombre-de-las-ratas/

La versión actual presenta una línea de tiempo con nueve acontecimientos, una explicación desplegable inmediatamente debajo de cada acontecimiento en celulares, un desarrollo académico organizado en tres capítulos y los cinco integrantes del Grupo 1 (sin legajos en la página pública).

El sitio se publica desde `index.html` en la rama `main` mediante GitHub Pages.
